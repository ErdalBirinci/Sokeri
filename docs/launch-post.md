Title: I built a free, open-source browser extension for Libre/Dexcom glucose
readings — Sokeri

---

Hi all — I'm a T1-adjacent developer (say who you are in one honest sentence)
and I got tired of reaching for my phone, so I built **Sokeri**: two tiny
Chrome extensions (FreeStyle Libre via LibreView, Dexcom G6/G7 via Share) that
put the live glucose value on the toolbar badge, with trend arrow, chart,
time-in-range stats and threshold alerts a click away.

- Free, no accounts, no analytics, no ads — everything stays in the browser
- Alerts with snooze, repeat, night escalation for lows, signal-loss watch
- Reports view: TIR bar, weekly pattern heatmap, PDF report, clinic mode
- Open source (MIT), English + Finnish UI: <repo link>

It's an unofficial community build using the same sharing APIs as LibreLinkUp /
Dexcom Share — manufacturers can change those at any time. Not a medical
device, 18+, always confirm on your sensor.

Happy to take bug reports and feature ideas here or on GitHub. If it helps
you, a share means more than anything.
